尚硅谷智慧校园项目：
本项目是基于前后端分离架构的智慧校园系统实现

项目简介
项目包含了前端展示和后端服务两部分。前端采用 HTML、CSS 及 Vue 框架实现页面效果展示，后端则采用 SpringBoot 框架搭建，具备数据库支持。

前端技术栈
HTML：用于构建网页结构
CSS：用于美化网页样式
Vue：前端框架，实现动态交互效果

后端技术栈
SpringBoot：后端框架
数据库：存储项目数据

本项目包含了以下几个主要功能模块：
用户管理：实现用户注册、登录、个人信息管理等功能
课程管理：实现课程信息的增删改查
成绩管理：实现学生成绩的录入、查询、修改等功能
教师管理：实现对教师信息的管理
学生管理：实现对在校学生信息的管理
